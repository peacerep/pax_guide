# PA-X guide — editorial review

**[Open the review site](https://peacerep.github.io/pax_guide/)**

This is a draft guide for reviewing PA-X explanations, worked questions, search guidance and source links. It is labelled **Review edition** throughout; it is not a replacement for the published PA-X codebooks.

The site has two parts: the [guide](https://peacerep.github.io/pax_guide/) and a [terminology reference](https://peacerep.github.io/pax_guide/terminology.html). The three worked-question videos open on YouTube. A reading-edition PDF is available from the guide.

## Suggested review points

- Are the inclusion criteria, metadata descriptions and topic definitions accurate and clear?
- Do the three worked questions show useful, repeatable routes through PA-X?
- Are the limits on interpreting agreement text and coded data stated clearly?
- Are the links and examples suitable for an academic and policy audience?

Please identify the page section and the wording or link when suggesting a change. Review comments can be sent to the project team or recorded as GitHub issues.

The repository contains only the files needed for this public review site. Source audits, internal editorial notes and local screen recordings are kept outside it.
